# Стена

Личная «стена» в духе ВКонтакте: имя и круглый аватар наверху на зимнем фоне (снег на canvas + гирлянда), ниже — гостевая книга с комментариями, лайками/дизлайками и антиспамом. Плюс `/activ` — журнал посещений.

## Настройка перед запуском

1. **Имя** — открой `config.json` и впиши своё имя:
   ```json
   { "ownerName": "Твоё Имя" }
   ```
2. **Аватар** — положи любой `.png` / `.jpg` / `.webp` файл (с любым названием) в папку `avatar-source/`. Сервер сам найдёт первый подходящий файл и отдаст его как круглый аватар. Если папка пустая — покажется дефолтная заглушка.
3. **Звук уведомлений** (необязательно) — положи любой `.mp3` / `.wav` / `.ogg` / `.m4a` файл (тоже с любым названием) в папку `sound-source/`. Он будет проигрываться при публикации комментария/ответа и при лайке/дизлайке. Если папку оставить пустой — просто не будет звука, тосты всё равно будут показываться.
4. **Соцсети** — открой `socials.json` и впиши ссылки на свои профили (пустая строка = иконка не показывается):
   ```json
   {
     "telegram": "https://t.me/username",
     "telegram_channel": "https://t.me/channelname",
     "spotify": "",
     "x": "",
     "pinterest": "",
     "brawlstars": "",
     "discord": "",
     "tiktok": ""
   }
   ```
   Иконки при желании кладутся в папку `social-icons/` — каждая под своим именем файла (`.png` / `.jpg` / `.webp` / `.svg`):

   | Платформа | Имя файла |
   |---|---|
   | Telegram | `t.png` |
   | Telegram-канал | `tc.png` |
   | Spotify | `s.png` |
   | X (Twitter) | `x.png` |
   | Pinterest | `p.png` |
   | Brawl Stars | `b.png` |
   | Discord | `d.png` |
   | TikTok | `tk.png` |

   Если файла для платформы нет — вместо иконки покажется просто цветной кружок с короткой подписью (TG, SP, X и т.д.), ссылка при этом всё равно рабочая. Точные фирменные логотипы (особенно Brawl Stars) сюда не встроены намеренно — безопаснее взять официальные иконки самому, чем гадать с их стилем.
5. **Аватары для комментаторов** — положи 5 (или сколько хочешь) круглых картинок в папку `commenter-avatars/`, названия файлов любые. Они появятся как варианты в пикере при написании комментария.
6. **Бан-слова** — впиши плохие слова/корни (по одному на строку) в `banwords.txt`. Комментарии со ссылками банятся автоматически, вписывать их не нужно.
7. **Пароль админки** — по умолчанию лежит в `admin.json` (`"кириешки"`), но этот файл **в `.gitignore` и не попадёт в git**. Для продакшена (Render) задай переменную окружения `ADMIN_PASSWORD` в настройках сервиса — так пароль не будет светиться в репозитории вообще. `admin.json` — только для локальной разработки.

## Локальный запуск

```bash
npm install
npm start
```

Открыть http://localhost:3000, журнал посещений — http://localhost:3000/activ

## Деплой на Render.com

1. Залить папку в git-репозиторий.
2. Render → **New → Web Service** → подключить репозиторий.
3. **Build Command:** `npm install`, **Start Command:** `npm start`, **Environment:** Node.
4. Не забудь либо положить аватар в `avatar-source/` и закоммитить его (учти — по умолчанию он в `.gitignore`, убери файл из игнора или добавь через `git add -f`), либо загрузить его на сервер уже после деплоя.

## Хранение данных

В отличие от мини-мессенджера, здесь используется **простое файловое хранилище** (`data/comments.json`, `data/visits.json`) — комментарии и посещения переживают перезапуск процесса. Но учти: на бесплатном тарифе Render диск эфемерный — **redeploy или пересоздание сервиса всё равно стирает файлы**. Если это важно, следующий шаг — Render Persistent Disk или БД (Postgres).

## Что реализовано

- Аватар и имя владельца, зимний анимированный фон (снег на canvas + гирлянда с мерцающими лампочками)
- **Иконки соцсетей слева от аватара** (Telegram, Telegram-канал, Spotify, X, Pinterest, Brawl Stars, Discord, TikTok) — ссылки из `socials.json`, иконки из `social-icons/` с фолбэком на цветную подпись, если файла нет. На мобильных иконки уходят под аватар отдельной строкой
- **Выбор аватара при комментировании** — 5+ готовых картинок из `commenter-avatars/`; без выбора аватара опубликовать нельзя (всплывает предупреждение с тем же пикером)
- **Бан-слова и автомодерация** — комментарий с запрещённым словом или ссылкой (ссылки банятся всегда) публикуется, но его текст заменяется на «Злой комментарий содержащий оскорбление :D» и показывается как блюр-спойлер (тап/клик — снять блюр), как в Telegram
- **Админка на `/admin`** (пароль в `admin.json` или `ADMIN_PASSWORD`) — таблица всех комментариев с IP и флагом нарушения, правка и удаление (с каскадным удалением ответов), плюс вкладка «География» — разбивка посещений `/activ` по странам (geoip-lite, офлайн, без сторонних API)
- **Архив старых записей** — кнопка «Архив» перед формой комментария читает `.txt`-файлы из `archive/` (формат: `Имя:` / `Дата:` / `Текст:`, блоки разделены `---`) и показывает их с предупреждением, что отвечать/голосовать за них нельзя. Наполняешь архив сам — например, вручную сохраняя туда то, что удалил через админку
- Комментарии: имя + текст, без регистрации
- **Ответы на комментарии** (один уровень тредов) — кнопка «Ответить» открывает форму прямо под комментарием
- **Сортировка**: «Новые» / «Популярные» (по разнице лайков и дизлайков)
- Лайк/дизлайк под каждым комментарием (можно снять голос повторным кликом, голос привязан к IP)
- Точная дата и время каждого комментария
- Антиспам: 1 комментарий (или ответ) с одного IP в 1 минуту, с таймером обратного отсчёта на клиенте и проверкой на сервере
- **Toast-уведомления** в стиле настоящего Steam: снизу справа, со срезанным углом, тёмно-синяя панель, голубая полоса и блик сверху, иконка + заголовок + подзаголовок — плюс звук из `sound-source/`. Цвет панели и иконки меняется по типу события: зелёный для лайка, красный для дизлайка, голубой для комментария, фиолетовый для ответа, серый для снятого голоса
- **Взрыв частиц** в точке клика при лайке/дизлайке + короткая вспышка рамки самой карточки в тот же цвет
- `/activ` — журнал посещений: IP, устройство, браузер, ОС, реферер (откуда пришли), язык браузера, часовой пояс, разрешение экрана и вьюпорта, дата/время, какая страница открывалась. **Ссылки на неё на главной странице больше нет** — доступна только по прямому URL
- Более детализированный зимний фон: звёзды с мерцанием, луна, «кристальные» снежинки вперемешку с обычными, морозные узоры по углам, гирлянда с шарами-игрушками и сосульками, сугроб с силуэтами ёлок и снеговика внизу

## ⚠️ Важно про `/activ`

Страница `/activ` сейчас **открыта всем, кто знает ссылку** — без пароля. Она показывает IP-адреса всех посетителей, что само по себе персональные данные. Если планируешь давать ссылку на сайт кому-то, кроме себя, — стоит закрыть `/activ` паролем (простейший вариант: Basic Auth через переменную окружения) прежде чем публиковать сайт широко. Могу добавить, если нужно.

## Разбор User-Agent

Определение ОС/браузера/устройства — простое, через регулярки, без сторонних библиотек (чтобы не тянуть лишние зависимости). Не идеально точное для экзотических браузеров, но покрывает основные случаи (Windows/macOS/Linux/iOS/Android, Chrome/Firefox/Safari/Edge/Opera).
